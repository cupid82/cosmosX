02 — How it comes apart

Every star knows
where it started
and where it lands.

Each particle carries two coordinates: the pixel it was born from, and a destination somewhere in the surrounding void. Scroll position blends between them — but never in a straight line.

  1. S1

    Sample

    The source frame is read once into an offscreen canvas. Bright pixels emit more particles than dark ones, so the spiral structure survives the translation.

  2. S2

    Stagger

    Release time is a function of radius. The outer arms shear away first; the nucleus is the last thing left burning.

  3. S3

    Unwind

    Inner particles sweep through a wider angle than outer ones — the same differential rotation that wound the arms up in the first place, run backwards.

  4. S4

    Disperse

    Turbulence peaks at the halfway mark and returns to zero, so paths bow outward mid-flight and still land exactly on target.
